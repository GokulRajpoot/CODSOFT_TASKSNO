# CODSOFT - Task 2

## Student Grade Calculator

### Description

The Student Grade Calculator is a Java console-based application that calculates a student's total marks, average percentage, and grade based on the marks obtained in each subject.

The user enters the number of subjects and the marks obtained in each subject. The program validates the input, calculates the total marks and average percentage, and assigns a grade based on the calculated percentage.

## Features

- Allows the user to enter the number of subjects.
- Accepts marks for each subject out of 100.
- Validates marks between 0 and 100.
- Calculates total marks.
- Calculates average percentage.
- Assigns a grade based on the average percentage.
- Displays the final result clearly.
- Handles invalid input.

## Grade Scale

## How to Run

### 1. Open the Project

Open the `Task-2-Student-Grade-Calculator` folder in a Java-supported IDE such as:

- IntelliJ IDEA
- Eclipse
- Visual Studio Code
- NetBeans

### 2. Compile the Program

`javac StudentGradeCalculator.java`

### 3. Run the Program

`java StudentGradeCalculator`

How the Program Works
1. The program asks the user to enter the number of subjects.
2. The user enters the marks obtained for each subject.
3. The program validates that each mark is between 0 and 100.
4. The program calculates the total marks.
5. The average percentage is calculated by dividing total marks by the number of subjects.
6. A grade is assigned according to the average percentage.
7. The final result is displayed.
